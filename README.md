# Authelia OIDC Client Generator

A browser-based generator for Authelia OpenID Connect client configuration.

## Features

- Generate OIDC client id and secret locally
- Generate Authelia PBKDF2-SHA512 client secret hashes
- Export Authelia YAML client configuration
- Static deployment friendly (Cloudflare Pages)

## Security

Secrets are generated locally in the browser and are never uploaded.
